# Community conduct

AI Creative Canvas welcomes focused, respectful collaboration.

## Expected behavior

- Discuss ideas and code without attacking people.
- Give actionable feedback and assume good faith.
- Respect privacy, copyright, trademarks, and confidential information.
- Remove API keys, personal data, private prompts, and customer assets from reports.
- Accept maintainer decisions about project scope and release safety.

## Unacceptable behavior

Harassment, threats, discriminatory language, deliberate disruption, impersonation, secret disclosure, and publication of private material are not accepted.

## Reporting

For ordinary conduct concerns, contact the maintainer through a private GitHub channel. For security issues, use the repository's private security advisory form. Reports will be reviewed in context, and maintainers may edit or remove content or restrict participation when needed to protect the community.
