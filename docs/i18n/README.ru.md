# AI Creative Canvas

[English](../../README.md) · [简体中文](./README.zh-CN.md) · [日本語](./README.ja.md) · [한국어](./README.ko.md) · [Español](./README.es.md) · [Português](./README.pt-BR.md) · [Français](./README.fr.md) · [Deutsch](./README.de.md) · Русский · [العربية](./README.ar.md)

AI Creative Canvas — это локально ориентированное рабочее пространство с открытым исходным кодом для генерации изображений, управления товарными материалами, сборки страниц товара и работы на бесконечном холсте.

## Возможности

- Генерация по промпту, референсные изображения, продолжение редактирования, копирование промпта и история задач.
- Бесконечный холст с кадрами, текстом, фигурами, слоями, масштабированием, панорамированием и сохранением проектов.
- Планирование длинных страниц по таблице и композиция нескольких экранов.
- Локальные аккаунты, сессии, статистика использования, отзывы и ограничения задач на пользователя.
- Пользовательский список моделей хранится в браузере; endpoints и ключи контролирует администратор.
- Диалоги, проекты и материалы по умолчанию сохраняются в `runtime/`.
- Необязательная резервная копия в S3-совместимое хранилище.

## Быстрый старт

Требуется Node.js 24 или новее.

```bash
npm install
npm start
```

Рабочее пространство: <http://127.0.0.1:5173>

Панель администратора:

```bash
npm run admin
```

Панель: <http://127.0.0.1:5188>. Пароль администратора задаётся при первом запуске; пароля по умолчанию нет.

## Основные параметры

| Переменная | По умолчанию | Назначение |
| --- | ---: | --- |
| `PORT` | `5173` | Порт рабочего пространства |
| `ADMIN_PORT` | `5188` | Порт панели администратора |
| `MAX_IMAGE_UPLOAD_MB` | `64` | Лимит загрузки изображения |
| `AI_IMAGE_MAX_CONCURRENCY` | `8` | Параллельность задач изображений |

Подробности: [справочник конфигурации](../CONFIGURATION.md) и [сценарии](../CASES.md).

## Ограничения

Это техническая предварительная версия для локального или частного сетевого развёртывания, а не multi-tenant SaaS. Локальное хранилище остаётся основным, облако — только необязательная резервная копия. Восстановление из облака и разрешение конфликтов пока не реализованы.
