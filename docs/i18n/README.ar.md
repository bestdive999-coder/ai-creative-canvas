# AI Creative Canvas

[English](../../README.md) · [简体中文](./README.zh-CN.md) · [日本語](./README.ja.md) · [한국어](./README.ko.md) · [Español](./README.es.md) · [Português](./README.pt-BR.md) · [Français](./README.fr.md) · [Deutsch](./README.de.md) · [Русский](./README.ru.md) · العربية

AI Creative Canvas هي مساحة عمل مفتوحة المصدر، محلية أولاً، لإنشاء الصور بالذكاء الاصطناعي وإدارة أصول المنتجات وتركيب صفحات التفاصيل والعمل على لوحة لا نهائية.

## الميزات الرئيسية

- إنشاء بالاعتماد على الوصف، صور مرجعية، متابعة تعديل الصور، نسخ الأوصاف وسجل المهام.
- لوحة لا نهائية تضم الإطارات والنصوص والأشكال والطبقات والتكبير والتحريك وحفظ المشاريع.
- تخطيط صفحات التفاصيل باستخدام الجداول وتركيب عدة شاشات.
- حسابات وجلسات واستخدام وملاحظات وحدود مهام لكل مستخدم محلياً.
- يمكن لكل مستخدم حفظ قائمة نماذجه في المتصفح؛ أما نقاط الخدمة والمفاتيح فيديرها المسؤول.
- تحفظ المحادثات والمشاريع والأصول افتراضياً في `runtime/` محلياً.
- نسخ احتياطي اختياري إلى تخزين متوافق مع S3.

## البدء السريع

يتطلب Node.js 24 أو أحدث.

```bash
npm install
npm start
```

مساحة العمل: <http://127.0.0.1:5173>

لوحة الإدارة:

```bash
npm run admin
```

لوحة الإدارة: <http://127.0.0.1:5188>. يتم إنشاء كلمة مرور المسؤول عند التشغيل الأول ولا توجد كلمة مرور افتراضية.

## أهم المعاملات

| المتغير | الافتراضي | الغرض |
| --- | ---: | --- |
| `PORT` | `5173` | منفذ مساحة العمل |
| `ADMIN_PORT` | `5188` | منفذ الإدارة |
| `MAX_IMAGE_UPLOAD_MB` | `64` | حد رفع الصورة |
| `AI_IMAGE_MAX_CONCURRENCY` | `8` | التزامن لمهام الصور |

راجع [مرجع الإعدادات](../CONFIGURATION.md) و[حالات الاستخدام](../CASES.md).
