# AI Creative Canvas

[English](../../README.md) · [简体中文](./README.zh-CN.md) · [日本語](./README.ja.md) · 한국어 · [Español](./README.es.md) · [Português](./README.pt-BR.md) · [Français](./README.fr.md) · [Deutsch](./README.de.md) · [Русский](./README.ru.md) · [العربية](./README.ar.md)

AI Creative Canvas는 AI 이미지 생성, 상품 에셋 관리, 상세 페이지 구성, 무한 캔버스 편집을 위한 로컬 우선 오픈 소스 작업 공간입니다.

## 주요 기능

- 프롬프트 기반 생성, 참조 이미지, 이미지 이어서 편집, 프롬프트 복사, 작업 기록.
- 프레임, 텍스트, 도형, 레이어, 확대/축소, 이동, 프로젝트 저장을 지원하는 무한 캔버스.
- 스프레드시트 기반 상세 페이지 계획과 여러 화면 구성.
- 로컬 계정, 세션, 사용량, 피드백, 사용자별 작업 제한.
- 브라우저에서 사용자별 이미지 모델 목록을 선택할 수 있으며, 엔드포인트와 키는 관리자가 보관합니다.
- 대화, 프로젝트, 에셋은 기본적으로 로컬 `runtime/`에 저장됩니다.
- S3 호환 스토리지로 선택적 클라우드 백업을 지원합니다.

## 빠른 시작

Node.js 24 이상이 필요합니다.

```bash
npm install
npm start
```

직원 작업 공간: <http://127.0.0.1:5173>

관리자 작업 공간:

```bash
npm run admin
```

관리자 화면: <http://127.0.0.1:5188>. 첫 실행 시 관리자 비밀번호를 직접 설정하며 기본 비밀번호는 없습니다.

## 주요 매개변수

| 변수 | 기본값 | 용도 |
| --- | ---: | --- |
| `PORT` | `5173` | 직원 서비스 포트 |
| `ADMIN_PORT` | `5188` | 관리자 서비스 포트 |
| `MAX_IMAGE_UPLOAD_MB` | `64` | 이미지 업로드 한도 |
| `AI_IMAGE_MAX_CONCURRENCY` | `8` | 이미지 작업 동시성 |

전체 설정은 [설정 문서](../CONFIGURATION.md), 실제 흐름은 [사례 문서](../CASES.md)를 확인하세요.

## 데이터 경계

로컬 또는 사설 네트워크 배포를 위한 기술 프리뷰입니다. 로컬 저장이 원본이며 클라우드는 선택적 백업입니다. 직원 화면은 계속 로컬 데이터를 읽고 클라우드 복원과 충돌 해결은 아직 제공하지 않습니다.
