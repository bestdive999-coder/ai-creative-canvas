# AI Creative Canvas

[English](../../README.md) · [简体中文](./README.zh-CN.md) · 日本語 · [한국어](./README.ko.md) · [Español](./README.es.md) · [Português](./README.pt-BR.md) · [Français](./README.fr.md) · [Deutsch](./README.de.md) · [Русский](./README.ru.md) · [العربية](./README.ar.md)

AI Creative Canvas は、AI 画像生成、商品アセット管理、商品詳細ページの構成、無限キャンバス編集を行うローカル優先のオープンソース・ワークスペースです。

## 主な機能

- プロンプト生成、参照画像、画像の続き編集、プロンプトコピー、タスク履歴。
- フレーム、テキスト、図形、レイヤー、ズーム、パン、プロジェクト保存に対応した無限キャンバス。
- スプレッドシートを使った詳細ページ計画と複数画面の構成。
- ローカルアカウント、セッション、利用量、フィードバック、ユーザー別タスク制限。
- ユーザーごとのブラウザ内モデルリスト。エンドポイントとキーは管理者が管理します。
- 会話、プロジェクト、アセットは標準でローカル `runtime/` に保存。
- S3 互換ストレージへの任意のクラウドバックアップ。

## クイックスタート

Node.js 24 以上が必要です。

```bash
npm install
npm start
```

従業員ワークスペース: <http://127.0.0.1:5173>

管理ワークスペース:

```bash
npm run admin
```

管理画面: <http://127.0.0.1:5188>。初回起動時に管理者パスワードを設定します。既定のパスワードはありません。

## 代表的なパラメーター

| 変数 | 既定値 | 用途 |
| --- | ---: | --- |
| `PORT` | `5173` | 従業員サービスのポート |
| `ADMIN_PORT` | `5188` | 管理サービスのポート |
| `MAX_IMAGE_UPLOAD_MB` | `64` | 画像アップロード上限 |
| `AI_IMAGE_MAX_CONCURRENCY` | `8` | 画像タスクの同時実行数 |

詳細は [設定リファレンス](../CONFIGURATION.md) を参照してください。ワークフロー例は [ケース集](../CASES.md) にあります。

## データ境界

ローカルまたはプライベートネットワーク向けの技術プレビューです。ローカル保存が一次データで、クラウドは任意のバックアップです。クラウド復元と競合解決はまだ実装していません。
